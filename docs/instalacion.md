# Instalación y uso

## Requisitos
Una cuenta de Claude con las Skills habilitadas (planes Pro, Max, Team o Enterprise).

## Pasos
1. Descarga `auditor-iso45001-co.zip` desde **Releases**. No lo descomprimas.
2. En Claude, abre **Configuración → Capacidades** y confirma que las Skills estén activas.
3. En la sección **Skills**, elige **Subir skill** y selecciona el `.zip`.
4. Actívala.

## Frases para empezar
- "Planea la auditoría interna del SG-SST para una empresa de 120 trabajadores, riesgo V, con 3 sedes."
- "Dame la lista de verificación para auditar el proceso de compras y contratistas."
- "Redacta y clasifica este hallazgo: …"
- "Haz el plan de acción para estas 4 no conformidades."
- "Arma el informe de auditoría con estos hallazgos."

## Consejos
- Entre más evidencia concreta des (códigos, fechas, muestras), mejores serán los hallazgos.
- Nunca pegues datos personales de trabajadores (cédulas, diagnósticos). Usa cargos o códigos.
